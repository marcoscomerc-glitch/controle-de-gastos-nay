# Controle de Gastos — Nayane Graziele

PWA de controle financeiro pessoal.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub (ex: `controle-de-gastos`)
2. Faça upload dos arquivos: `index.html`, `manifest.json`, `sw.js`
3. Vá em **Settings → Pages → Source → Deploy from branch → main → / (root)**
4. Aguarde ~1 min e acesse: `https://SEU_USUARIO.github.io/controle-de-gastos`

## Como instalar no celular

**Android (Chrome):** Abra o link → menu ⋮ → "Adicionar à tela inicial"  
**iPhone (Safari):** Abra o link → botão Compartilhar → "Adicionar à Tela de Início"

## Estrutura
- `index.html` — app completo
- `manifest.json` — configuração PWA (nome, cores, ícone)
- `sw.js` — service worker (funciona offline)
